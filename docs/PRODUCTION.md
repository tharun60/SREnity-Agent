# Production hardening checklist

- Run collectors with least-privilege read-only RBAC and keep the remediation identity separate.
- Replace webhook URLs and API keys with a secret manager; redact logs before model calls.
- Require signed, expiring approvals bound to the exact action and incident.
- Execute only typed actions; avoid arbitrary shell generated by a model.
- Apply timeouts, retries with jitter, circuit breakers, query budgets, and result-size limits.
- Persist incidents in a transactional store with idempotency and optimistic locking.
- Add OpenTelemetry spans around the agent loop and each tool call; correlate by incident ID.
- Export agent latency, tool errors, model tokens/cost, confidence, and action outcomes.
- Protect against prompt injection inside logs and events: treat telemetry as untrusted data.
- Evaluate against frozen incident replays before prompt, model, connector, or policy changes.
- Add leader election, work queues, per-cluster rate limits, and degraded-mode behavior.
- Define ownership: the agent assists responders; it does not own production safety decisions.
